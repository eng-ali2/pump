# تطبيق مراقبة مضخات وحدة الأسفلت

تطبيق ويب يتثبت على الموبايل مثل التطبيقات العادية (PWA).

**الموظف** يدخل بحسابه، ويسجل قراءات المضخة. الاسم والتاريخ يتعبّون تلقائياً، والوقت ينسجل لوحده. يكدر يسجل الصيانة اليومية والأعطال أيضاً.

**المشرف** عنده:
- لوحة تحكم بحالة كل المضخات اليوم
- التنبيهات (القراءات اللي تتجاوز الحدود المسموحة)
- التقارير اليومية والأسبوعية والشهرية، وبيها أكثر المضخات أعطالاً
- تصدير لـ Excel وطباعة PDF

---

## ١) تجربة سريعة (بدون أي إعداد)

ارفع المجلد كله على Netlify (سحب وإفلات)، وافتح الرابط.
التطبيق يشتغل بـ**الوضع التجريبي** وبيه بيانات وهمية:

- المشرف: `admin` / `admin`
- الموظف: `ali` / `1234`

⚠️ بالوضع التجريبي، البيانات تنحفظ على نفس الجهاز فقط ولا توصل للمشرف. للتشغيل الحقيقي اتبع الخطوة ٢.

---

## ٢) التشغيل الحقيقي (مجاني) عن طريق Firebase

Firebase هو اللي يخزن البيانات، حتى كل الموظفين يرسلون للمشرف.

1. افتح **console.firebase.google.com** وسجّل بحساب Google.
2. اضغط **Create a project**، سمّه مثلاً `asphalt-pumps`. تكدر تطفي Google Analytics.
3. من القائمة اختر **Build ← Authentication** واضغط **Get started**. اختر **Email/Password** وفعّله (Enable)، ثم Save.
4. من القائمة اختر **Build ← Firestore Database** واضغط **Create database**. اختر أقرب موقع (مثلاً `eur3` أو `europe-west`) ثم **Start in production mode**.
5. بنفس صفحة Firestore افتح تبويب **Rules**، امسح الموجود، والصق محتوى ملف `firestore.rules` كاملاً، ثم **Publish**.
6. ارجع للصفحة الرئيسية للمشروع واضغط أيقونة الويب `</>`. سمّ التطبيق واضغط Register. راح يطلعلك كود بيه `firebaseConfig = {...}`.
7. افتح ملف `config.js` وبدّل السطر `window.FIREBASE_CONFIG = null;` بالإعدادات اللي نسختها:
   ```js
   window.FIREBASE_CONFIG = {
     apiKey: "...",
     authDomain: "...",
     projectId: "...",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "..."
   };
   ```
8. ارفع المجلد من جديد على Netlify.
9. في Firebase روح على **Authentication ← Settings ← Authorized domains** وأضف رابط موقعك (مثل `mysite.netlify.app`).
10. افتح الموقع. أول مرة راح تطلع شاشة **الإعداد الأول** حتى تسوي حساب المشرف.
11. من تبويب **المضخات** أضف المضخات وحدد حدود التنبيه لكل وحدة، ومن تبويب **المستخدمين** أضف حسابات الموظفين.

## ٣) التثبيت على الموبايل

- **أندرويد (Chrome):** افتح الرابط، ومن القائمة ⋮ اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
- **آيفون (Safari):** افتح الرابط، واضغط زر المشاركة ثم **إضافة إلى الشاشة الرئيسية**.

## ملاحظات

- **العمل بدون إنترنت:** إذا الموظف بمكان ما بيه نت، القراءة تنحفظ على الجهاز وتنرسل تلقائياً أول ما يرجع الاتصال. هذا بالتشغيل الحقيقي (Firebase) فقط.
- **نسيان كلمة المرور:** تحذف المستخدم من Firebase ← Authentication، وتضيفه من جديد باسم مستخدم ثاني.
- **إيقاف موظف:** من تبويب المستخدمين اضغط **إيقاف**.
- **الوحدات:** الافتراضية هي bar للضغط و°C للحرارة وA للأمبير. تكدر تغيّرها من ملف `store.js` (قائمة FIELDS بأول الملف).
- **ملاحظة على الأسماء:** M.S تعني Mechanical Seal، وP section تعني ضغط السحب (Suction).
- **الخطة المجانية لـ Firebase** (Spark) تكفي بسهولة لوحدة بيها عشرات المضخات وقراءات يومية.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `app.js` | كل الشاشات والتقارير |
| `store.js` | حفظ البيانات (تجريبي / Firebase) والحقول |
| `config.js` | إعدادات Firebase ← **هذا الملف الوحيد اللي تعدّله** |
| `styles.css` | التصميم |
| `manifest.json` + `sw.js` + `icons/` | ملفات الـ PWA (التثبيت والعمل بدون نت) |
| `firestore.rules` | قواعد الحماية، تنلصق في Firebase |
